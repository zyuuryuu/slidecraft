# 入力サンプル: テンプレート

`Midnight_Executive_30_TemplateOnly.pptx` は SlideCraft の canonical 30 レイアウト（`LAYOUT_NAMES` の名前を
そのまま持つ開発用マスター）で、#117 まではアプリの既定ビルトインとして同梱していた。同梱をやめて
ここに**入力サンプル**として置いている（アプリの MasterPicker「＋取込」から取り込めば従来どおり使える）。
テストの一部（タイトル可読性・病理検出・chrome ゲート等）は、走査範囲を縮めないためこのファイルを直接読むので、
消すときはそれらのテストも併せて見直すこと。これを patch・再生成していた開発スクリプト（`scripts/rebuild-template.ts`
ほか）は #117 で引退したので、必要なら git 履歴から復元する。
